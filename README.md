# chrome-extensions

A collection of small Chrome extensions.

| Extension | Description |
| --- | --- |
| [claude-usage-ext-chrome](claude-usage-ext-chrome/) | Popup showing your Claude account usage limits (session + weekly). |
| [armenian-translit-ext-chrome](armenian-translit-ext-chrome/) | Type Armenian with English letters: "Barev" becomes "Բարև" as you type. |

Each folder is a standalone unpacked extension — see its own README for install
instructions.
